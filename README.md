# Landing Page "Em Breve"

Este repositório contém o código para uma landing page "Em Breve" (Coming Soon), ideal para gerar expectativa e capturar leads antes do lançamento oficial de um produto ou serviço.

## Objetivo do Projeto

O principal objetivo desta landing page é criar um **buzz inicial** e coletar informações de contato (e-mails) de pessoas interessadas no lançamento. Ela foi projetada para ser simples e focada, direcionando o usuário para a ação de se inscrever para notificações.

## Características Principais

* **Título Principal (Headline):** Chama a atenção e cria curiosidade. Exemplo: "Prepare-se: O Aplicativo que Vai Revolucionar Sua Produtividade Chega em Breve!"
* **Descrição Concisa:** Explica o valor da solução de forma rápida e clara. Exemplo: "Simplifique suas tarefas diárias, organize seus projetos e aumente sua eficiência como nunca antes."
* **Seção de Prévia:** Exibe visuais do produto (mockups ou telas iniciais) para dar ao público uma ideia do que está por vir.
* **Contagem Regressiva:** Um temporizador que aumenta a expectativa e informa a data do lançamento.
* **Formulário de Leads:** Um campo simples de e-mail para que os usuários possam se inscrever e receber notificações.
* **Chamada para Ação (CTA):** Botões diretos e atrativos, como "Quero Ser Notificado!" ou "Entre na Lista de Espera".
* **Links para Redes Sociais:** Permite que os interessados acompanhem o desenvolvimento e interajam com a marca.

## Estrutura do Repositório

* `index.html`: O arquivo HTML principal da landing page.
* `styles.css`: O arquivo CSS responsável pela estilização e pelo visual minimalista da página.
* `scripts.js`: O arquivo JavaScript que gerencia a contagem regressiva e a funcionalidade do formulário.
* `assets/`: Pasta para armazenar imagens (como os mockups), ícones e outros recursos visuais.

## Como Usa.
3.  Abra o arquivo `index.html` no seu navegador para ver a página em ação.
